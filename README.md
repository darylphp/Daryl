# Suzuki Minivan Accessories WordPress Theme

## Overview
A modern, minimal WooCommerce-compatible WordPress theme designed for a Suzuki minivan accessories e-commerce store.

## Features

### Homepage Sections
- **Hero Section**: Large banner with Suzuki minivan and call-to-action button
- **Vehicle Selector Tool**: Interactive dropdown to select Suzuki model and year
- **Featured Categories**: Visual category blocks for browsing accessories
- **Trust Builders**: Key benefits like guaranteed fit, free shipping, expert support
- **Featured Products**: Grid display of popular accessories
- **Blog Snippets**: Latest guides and articles

### Design
- Clean, modern aesthetic
- Responsive layout
- Blue (#007BFF) and orange (#FF6600) accent colors
- Mobile-friendly design

## Installation

1. Upload the theme folder to `/wp-content/themes/`
2. Activate the theme in WordPress Admin > Appearance > Themes
3. Install WooCommerce plugin for e-commerce functionality
4. Add additional images for categories, trust icons, and blog posts to `/assets/images/`

## Customization

### Colors
Edit `style.css` to customize the color scheme:
- Primary Blue: `#007BFF`
- Primary Orange: `#FF6600`
- Success Green: `#28a745`

### Content
Edit `index.php` to modify:
- Hero headline and CTA text
- Vehicle models in dropdown
- Category names and descriptions
- Product information
- Blog post titles and excerpts
